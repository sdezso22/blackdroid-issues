# Blackdroid Issues

Public bug tracker and feature request board for [blackdroid.dev](https://blackdroid.dev).

The source code lives in a private repository — this repo exists only to collect
bug reports and feature requests via GitHub Issues.

## Report a bug

Use the [Bug report](../../issues/new?template=bug_report.yml) template and include:

- the page/tool where it happened (e.g. `/background-remover`, `/app/mailboxes`)
- what you expected vs. what actually happened
- browser + version (and OS if relevant)
- whether you were signed in (OAuth login) or using it anonymously
- reproduction steps — the more precise, the faster the fix

## Request a feature

Use the [Feature request](../../issues/new?template=feature_request.yml) template.
Describe the problem you're trying to solve, not just the solution you have in mind.

## Security issues

**Do not report vulnerabilities here.** See [SECURITY.md](SECURITY.md).
